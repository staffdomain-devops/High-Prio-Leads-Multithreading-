## RESOURCE SELECTION RULES

Work through these in order. Stop at the first match.

### Step 1 — Select ONE Case Study (used in Email 1)

Priority order:
1. INDUSTRY MATCH: Does any case study share the same or closely related industry as the prospect? If yes, use that case study.
2. ROLE MATCH: If no industry match, does any case study involve the same or closely related role/function being hired for? If yes, use that case study.
3. PAIN MATCH: If no role match, does any case study address the same core pain point (e.g. local talent shortage, scaling pressure, lean team, founder bottleneck)? If yes, use the most relevant one.
4. UNIVERSAL FALLBACK: If no match on any dimension, use CS01 (Oceanis International).

### Step 2 — Select ONE YouTube Video (used in Email 4)

Apply the same Industry > Role > Pain priority order. The video MUST be different from the case study selected (different company). If the best match is the same company as the case study, select the next-best match for YouTube.

### Step 3 — Select ONE Website Resource (used in Email 2)

Base this on the PRIMARY contact's title (the first contact listed).

- If the prospect is a Founder, Co-founder, CEO, MD, or Director: use WR02
- If the prospect title suggests operations, HR, or admin (COO, Operations Manager, HR Manager): use WR01
- If there is no prior offshore history evident: use WR03
- If industry suggests cost sensitivity (accounting, legal, small business): use WR04
- Default: use WR01

### Step 4 — Select ONE Website Resource (used in Email 5)

Must be DIFFERENT from the resource used in Email 2. Choose from:
- WR07 (FAQ) — best for leaving a low-friction exit ramp
- WR02 (Benefits of Outsourcing) — if not used in Email 2
- WR08 (Resource Hub) — general credibility leave-behind
